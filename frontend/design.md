# SIMS 设计规范（Billow 风格迭代）

> 登录页与登录后工作台统一为 Billow 柔和蓝青气质。  
> 气质关键词：**白底 + 蓝青光斑、顶栏导航、大圆角卡片、电光蓝 CTA、少框线**。

> 说明：早期 Gradia 紫系已由 Billow 蓝系接替；下列 Token 以当前实现为准。

---

## 2. 字体

### 2.1 字体家族

```css
--font-sans: "Plus Jakarta Sans", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif;
```

正文与标题统一使用同一无衬线家族，靠字号/字重建立层级（参考 Gradia）。

### 2.2 字号 · 字重 · 行高

| 层级 | 字号 | 字重 | 行高 | 字距 | 场景 |
|------|------|------|------|------|------|
| Display | 40–48px | 700–800 | 1.15 | -0.02em | 登录大标题、空态主文案 |
| H1 页标题 | 28–32px | 700 | 1.25 | -0.02em | 页面主标题 |
| H2 区块 | 20–22px | 600–700 | 1.3 | -0.01em | 卡片组标题、模块名 |
| H3 卡片标题 | 16–18px | 600 | 1.4 | 0 | 卡片内标题 |
| Body | 15–16px | 400 | 1.6 | 0 | 正文、表单内容 |
| Body SM | 14px | 400–500 | 1.5 | 0 | 表格、导航项 |
| Caption | 12–13px | 500–600 | 1.4 | 0.01em | 标签、时间、辅助说明 |

对比原则：**标题深色粗体 + 正文中灰常规**，避免标题与正文同色同重。

## 3. 间距

### 3.1 基础刻度（4px 网格）

| Token | 值 |
|-------|-----|
| `--space-1` | 4px |
| `--space-2` | 8px |
| `--space-3` | 12px |
| `--space-4` | 16px |
| `--space-5` | 20px |
| `--space-6` | 24px |
| `--space-8` | 32px |
| `--space-10` | 40px |
| `--space-12` | 48px |
| `--space-16` | 64px |

### 3.2 常用内外边距

| 场景 | 建议 |
|------|------|
| 页面内容区内边距 | 24–32px（移动端 16px） |
| 卡片内边距 | 24–32px |
| 表单项纵向间距 | 16–20px |
| 按钮组间距 | 12–16px |
| 顶栏高度 | 64px |
| 侧栏宽度 | 240px（折叠 72px） |

### 3.3 模块间距（呼吸感）

| 场景 | 建议 |
|------|------|
| 页标题 → 首个内容模块 | 32–40px |
| 模块与模块之间 | 24–32px |
| Bento / 卡片网格 gap | 20–24px |
| 登录壳层与视口边缘 | ≥ 24px |
| 区块标签 → 大标题 | 12–16px |

原则：**宁可多留白，也不要贴边堆砌**；参考站模块间常见 80px+ 级留白，业务后台收敛为上述刻度以免浪费可视区。

## 4. 组件样式

### 4.1 圆角

| Token | 值 | 用途 |
|-------|-----|------|
| `--radius-sm` | 12px | 输入框、小标签 |
| `--radius-md` | 16px | 下拉、对话框 |
| `--radius-lg` | 24px | 卡片、侧栏菜单块 |
| `--radius-xl` | 32px | 大面板、登录壳 |
| `--radius-pill` | 9999px | 按钮、导航 CTA、徽章 |

### 4.2 按钮

| 类型 | 背景 | 文字 | 圆角 | 阴影 | 内边距 |
|------|------|------|------|------|--------|
| Primary CTA | `#111827` | `#FFF` | pill | 无或极弱 | 12px 24px |
| Soft Primary | `#EDE9FE` | `#111827` | pill | `0 2px 8px rgba(124,58,237,0.08)` | 12px 24px |
| Ghost / Text | 透明 | `#4B5563` | pill | 无 | 12px 16px |
| Danger | Element 红系，圆角仍用 pill | — | pill | — | 同 Primary |

字重：500–600；禁止直角小按钮。

### 4.3 卡片

- 背景：`#FFFFFF`
- 圆角：`24px`
- 边框：`1px solid #E5E7EB`（可无边，仅靠阴影时需保证对比）
- 阴影：`var(--shadow-card)`
- 内边距：`24–32px`
- 可选用极弱角部渐变（暖黄 / 浅粉）做重点模块，参考 Features Bento

### 4.4 导航栏（顶栏）

- 背景：白 / 半透明白，**不要**实心蓝条
- 高度：64px
- Logo / 系统名：字重 700，色 `#111827`
- 中间信息（角色标签）：浅底 pill
- 右侧主操作：深色 pill 按钮风格头像区
- 底部分割：`1px solid #E5E7EB` 或仅阴影，忌厚重色带

### 4.5 侧栏

- 背景：`#FFFFFF` / `#F8F9FB`
- 激活项：浅紫底 `#EDE9FE` + 文字 `#7C3AED` 或近黑加粗
- 圆角菜单项：`12–16px`
- 无重阴影；右边框 `#E5E7EB`

### 4.6 输入框 / 表格

- 输入框圆角：`12px`；边框 `#E5E7EB`；聚焦环浅紫
- 表格容器包在卡片内；表头字重 600、字色 secondary；行高宽松

### 4.7 标签 / Badge

- 圆角 pill
- 分区标签：暖色底 + 深棕字，或浅紫底 + 主色字
- 未读角标：沿用危险色，pill 形

## 5. 整体布局结构（业务适配）

参考 Gradia「**外层渐变氛围 + 内层浅色内容壳**」：

```
┌─────────────────────────────────────────────┐
│  外层：紫粉渐变（--color-bg-outer）           │
│  ┌───────────────────────────────────────┐  │
│  │  内容壳：浅灰白 + 大圆角/满屏工作区     │  │
│  │  ┌ 顶栏（白、Logo 左 / 操作右）──────┐ │  │
│  │  ├ 侧栏 ─┬─ 主内容（卡片网格、留白）─┤ │  │
│  │  └──────┴──────────────────────────┘ │  │
│  └───────────────────────────────────────┘  │
└─────────────────────────────────────────────┘
```

- **登录/注册**：居中大圆角白卡片浮于渐变之上（最接近参考 Hero 壳层）。
- **已登录工作台**：顶栏 + 侧栏 + 主区；主区用卡片化模块，gap 20–24px，模拟 Bento 呼吸感，但不强行做成营销落地页。

---

## 6. 动效（克制）

- 过渡：`200–300ms`，`cubic-bezier(0.4, 0, 0.2, 1)`
- 悬停：阴影略升 / 浅紫底出现；避免强光晕与多阴影堆叠
- 页面切换：保持简洁，不做夸张位移
